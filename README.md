## My opinions on version control

What I like most about version control is that it acts as a safety net: I can experiment freely, knowing I can always go back to an earlier working version of my project.

What I find most challenging is keeping track of everything happening at once, such as branches, merges and conflicts, especially when remembering which command to use and what state my repository is in.
